🍕 Pizza Sales Analysis — SQL Project

An end-to-end SQL Data Analytics project focused on analyzing pizza sales data and extracting meaningful business insights through SQL queries.

📌 Project Overview

This project demonstrates the use of SQL to analyze pizza sales, orders, revenue, pizza sizes, categories, ordering patterns, and product performance.

The analysis includes both Basic and Advanced SQL queries.

🛠️ Technologies Used

- SQL
- Data Query Language (DQL)
- SQL Joins
- Aggregate Functions
- GROUP BY
- ORDER BY
- Date & Time Analysis
- Revenue Analysis

🔍 Analysis Performed

📊 Basic Analysis

- Retrieve the total number of orders placed.
- Calculate the total revenue generated from pizza sales.
- Identify the highest-priced pizza.
- Identify the most common pizza size ordered.
- Find the Top 5 most ordered pizza types along with their quantities.

🚀 Advanced Analysis

- Find the total quantity of each pizza category ordered using table joins.
- Determine the distribution of orders by hour of the day.
- Analyze the category-wise distribution of pizzas.
- Calculate the average number of pizzas ordered per day.
- Find the Top 3 pizza types based on revenue.
- Calculate the percentage contribution of each pizza type to total revenue.
- Analyze cumulative revenue generated over time.
- Find the Top 3 revenue-generating pizza types for each category.

🎯 Project Objective

The main objective of this project is to strengthen practical SQL and data analytics skills by converting pizza sales data into useful business insights.
